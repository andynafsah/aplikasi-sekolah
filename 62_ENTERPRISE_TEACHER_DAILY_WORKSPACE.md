Lanjutkan project ERP yang sudah ada.

Jangan membuat project baru.
Jangan mengubah modul yang sudah selesai kecuali diperlukan.

Gunakan RBAC, Assignment Engine, KBM Engine, Attendance Engine, Assessment Engine, Formula Engine, Auto Leger Engine, Rapor Engine, Calendar Engine, Notification Engine, Dashboard Engine, Print Engine, Audit Engine, Prisma ORM, Laravel API, React, Tailwind dan Mobile API yang sudah ada.

Implementasikan langsung production-ready.

==================================================

TARGET

Ubah menu "KBM Saya" menjadi Enterprise Teacher Daily Workspace.

Semua pekerjaan harian Guru, Wali Kelas dan Guru Mapel dilakukan dari satu halaman.

Zero Hardcode.
Zero Dummy Data.
Database Driven.
