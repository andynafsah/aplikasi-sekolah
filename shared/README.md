# 🤝 SHARED CODE & API SCHEMAS
# shared/README.md

Folder ini dirancang sebagai tempat penyimpanan skema validasi, tipe data TypeScript, konstanta, dan spesifikasi API kontrak yang dibagikan (*shared*) antara backend, frontend-web, dan generator Flutter.

---

## 📂 STRUKTUR DIREKTORI

*   `types/`: Definisi interface TypeScript global untuk entitas (Student, Teacher, Class, dsb).
*   `validators/`: Skema validasi masukan menggunakan Zod, menjamin konsistensi payload sebelum dikirim dari frontend ke backend.
*   `README.md`: Panduan sinkronisasi pustaka tipe data.
